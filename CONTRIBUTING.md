# Contributing

Takes is shared as is and kept by one person, so it does not take pull requests. A workflow closes each new one with a note.

- **Ideas, questions and bugs:** [Discussions](https://github.com/marvtub/takes-public/discussions).
- **Security problems:** see [SECURITY.md](SECURITY.md). Please don't post them in Discussions.
- **Your own version:** forks are welcome under the MIT license.
